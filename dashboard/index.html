How the radar scores

Implied value = TVL × multiple × growth × age × breadth. The multiple is not a guess: it is the category’s own FDV/TVL, the median market-cap-to-TVL of the snapshot’s token-having protocols in the same category (at least 3 with a market cap, else the global median shown in the stats above). Growth is the protocol’s 7-day TVL change, age is how long DefiLlama has tracked it with no token recorded, breadth is how many chains it runs on. No protocol name is ever special-cased — the same formula scores all 198 rows.

Eligibility is the snapshot’s own watchlist rule with the floor removed: no token recorded, and not a wrapped, staked or bridged product of a token that already trades. The 40-protocol watchlist is the floor, never the ceiling: this board adds 158 early protocols below it. “Records no token” is not proof a protocol has none — its DefiLlama record may simply not carry one. An implied value is this entry’s own claim, never a prediction that a token will launch.
